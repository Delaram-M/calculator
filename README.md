# Calculator Application
This project is a desktop calculator application supporting addition, subtraction, multiplication, and division operations.
This calculator has a GUI (graphical user interface) built using Java Swing.
Moreover, this project includes some tests written using JUnit.
The calculator application is in the src/main directory, and the tests are in the src/test directory.
